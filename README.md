# 配货表格查看器

一个简单易用的配货管理工具，支持多表格管理、商品配货操作和状态跟踪。

## 功能特性

### 表格管理
- 📥 导入数据：支持文本粘贴导入表格数据
- 📋 多表格管理：创建、查看、删除多个配货表格
- 📅 自动记录：保存表格的创建和更新时间

### 表格操作
- 📊 表格详情：查看表格中的所有商品信息
- 🔢 序号排序：点击序号字段进行正序排列
- 🔄 视图切换：支持切换显示/隐藏日期字段
- 🗑️ 表格删除：快速删除不需要的表格

### 商品配货
- 👆 滑动操作：左滑标记为有货，右滑标记为无货
- ✏️ 编辑功能：双击或双击编辑实际数量和生产日期
- 📱 移动端优化：支持触摸操作，适配移动设备

### 状态显示
- 🟢 有货：实际数量 ≥ 应发数量
- 🔴 无货：实际数量 = 0
- 🟡 少货：0 < 实际数量 < 应发数量
- ⚪ 未操作：尚未填写实际数量

## 使用说明

### 导入数据

点击"导入数据"按钮，按照以下格式粘贴数据：

```
光彩路
序号	商品名称	四位	量	箱
2	津华谷色苦荞片葱香味400g	2725	10	1.0
1	津华谷色苦荞片牛排味400g	0073	20	2.0
```

**格式说明：**
- 第一行：表格名称
- 第二行：表头（必须包含：序号、商品名称、四位、量、箱）
- 后续行：商品数据

### 配货操作

1. **快速标记**
   - 左滑商品行：标记为有货（实际数量 = 应发数量）
   - 右滑商品行：标记为无货（实际数量 = 0）

2. **编辑详情**
   - 双击商品行：打开编辑弹窗
   - 输入实际数量和生产日期
   - 点击确认保存

3. **排序功能**
   - 点击"序"字段：按序号正序排列
   - 点击其他字段：在升序/降序之间切换

### 视图切换

- 点击"切换"按钮：在标准视图和日期视图之间切换
- 标准视图：显示商品名称、四位、量、箱、实
- 日期视图：显示商品名称、生产日期

## 开发说明

### 本地运行

直接在浏览器中打开 `index.html` 文件即可使用。

### 数据存储

应用使用 IndexedDB 进行本地数据存储，数据保存在浏览器中，无需服务器支持。

### 主要模块

- **数据库管理**：`initDB()`, `getAllTables()`, `saveTable()`, `deleteTable()`
- **数据解析**：`parseTextData()`, `parseCSV()`
- **表格渲染**：`renderTableList()`, `renderTable()`
- **交互处理**：`setupTableListInteractions()`, `setupTableInteractions()`
- **状态计算**：`calculateStatus()`, `checkTableCompleted()`

## 注意事项

- 数据存储在浏览器本地，清除浏览器数据会丢失所有表格
- 建议定期导出重要数据
- 移动端使用时建议使用现代浏览器
